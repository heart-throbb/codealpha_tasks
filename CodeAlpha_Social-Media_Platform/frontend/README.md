# MiniSocial Frontend

This is the React frontend for the MiniSocial social media platform.

## Features

- Modern authentication pages for login and registration
- Home feed and post interactions
- User profiles and follow system
- Responsive layout with Tailwind CSS
- Profile image upload and preview

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React

## Scripts

- `npm install` - install dependencies
- `npm run dev` - start the development server
- `npm run build` - build the app for production
- `npm run preview` - preview the production build

## Development Notes

The frontend expects the backend API to be running at:

```text
http://localhost:5000/api
```
