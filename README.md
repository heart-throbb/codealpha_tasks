# CodeAlpha Tasks

A collection of full-stack web development projects built with modern technologies including React, Node.js, Express, and MongoDB.

## 📋 Projects

### 1. MiniSocial - Social Media Platform
A full-stack social media platform where users can register, log in, create posts, follow others, view profiles, and interact with content.

**Location:** `CodeAlpha_Social-Media_Platform/`

**Features:**
- User authentication and authorization
- Create, view, and manage posts
- Follow and unfollow users
- View user profiles and activity
- Upload profile pictures
- Responsive UI for desktop and mobile

**Tech Stack:**
- **Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Lucide React
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT authentication, Multer

[View MiniSocial README](./CodeAlpha_Social-Media_Platform/README.md)

---

### 2. E-commerce Store
A full-stack e-commerce web application with a customer-facing storefront featuring product browsing, cart management, checkout, and an admin dashboard.

**Location:** `CodeAplha_E-commerce_Store/`

**Features:**
- Customer registration and login
- Product listing and product detail pages
- Shopping cart and checkout flow
- Admin dashboard for managing products, orders, and users
- Secure authentication using JWT
- RESTful API backend with MongoDB storage

**Tech Stack:**
- **Frontend:** React, Vite, React Router DOM, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js, MongoDB with Mongoose, JWT Authentication, CORS support

[View E-commerce README](./CodeAplha_E-commerce_Store/README.md)
